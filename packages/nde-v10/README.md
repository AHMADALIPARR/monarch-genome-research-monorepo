# Near-death experience research branch (v10)

Four source-attributed research studies. Study counts are aggregate descriptions, not new individual-level observations.

**Invariant 1: provenance** — every research study is linked to a source document.
**Invariant 2: no mechanism promotion** — reported fractions and EEG observations do not establish an independently verified mechanism.
**Invariant 3: state measurement** — any future torus/entropy dataset must have matched, timestamped observations and its own acquisition provenance.
**Invariant 4: clinical separability** — NDEs, MKULTRA exposure reports, and post-recovery observations can share measurement dimensions without implying identical causes.

The Lean proofs are simple internal model properties, not proof of consciousness surviving death. No actual participant-level dataset or pre/post cognition scores are included. No inference about NDE-genome associations is made.

SPARQL files run against `nde_extension.ttl` with RDFLib. This extension deliberately leaves NDE and genome classes separate.
